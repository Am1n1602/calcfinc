# Ratio and metric reference

Generated by `scripts/gen_ratio_docs.py` from the registries; do not edit by hand.

A ratio's formula is what the engine evaluates. Inputs are reported metrics (second table of each section), other ratios, `share_price`, `period_days`, `prior(x)` (the same metric one comparable period earlier) and `ttm(x)` (the sum over the periods making up a year). A missing input gives `None` with a reason, except those listed as treated as 0. A ratio marked "not computed for" a sector returns `None` with the reason for it; so does every ratio built on it (net debt, for instance, for a bank).

## Generic

### Ratios and derived quantities

| Name | Unit | Formula | Meaning |
|---|---|---|---|
| `top_line` | amount | `revenue` | Revenue, or total income for banks / insurers - fallback `total_income` (revenue not reported; total_income used as the top line (bank / insurer format)) |
| `ebit` | amount | `pbt_before_exceptional + finance_costs` | EBIT - treated as 0 when not reported: `finance_costs`; not computed for: bank |
| `ebitda` | amount | `pbt_before_exceptional + depreciation + finance_costs - other_income` | EBITDA - treated as 0 when not reported: `finance_costs`; not computed for: bank |
| `operating_ebit` | amount | `revenue - employee_expense - depreciation - other_expenses` | Operating EBIT (excludes other income) - not computed for: bank |
| `total_debt` | amount | `borrowings_current + borrowings_noncurrent + debt_securities + deposits_debt` | Total debt - treated as 0 when not reported: `borrowings_current`, `borrowings_noncurrent`, `debt_securities`, `deposits_debt`; not computed for: bank |
| `net_debt` | amount | `total_debt - cash_and_equivalents` | Net debt |
| `capex` | amount | `abs(capex_ppe) + abs(capex_intangibles)` | Capital expenditure (a positive amount, whichever sign the source uses) - fallback `abs(capex_ppe)` (capex_intangibles not reported; capex is PP&E only); fallback `abs(capex_intangibles)` (capex_ppe not reported; capex is intangibles only) |
| `free_cash_flow` | amount | `operating_cash_flow - capex` | Free cash flow - not computed for: bank, insurer |
| `working_capital` | amount | `current_assets - current_liabilities` | Working capital - not computed for: bank, insurer |
| `nopat` | amount | `ebit * (1 - tax_expense / pbt)` | Net operating profit after tax (EBIT x (1 - effective tax rate)) - must be positive: `pbt` |
| `invested_capital` | amount | `total_debt + total_equity - cash_and_equivalents` | Invested capital (debt + equity - cash) |
| `eps` | per share | `eps_basic` | Earnings per share - fallback `eps_diluted` (basic EPS not reported; diluted EPS used); fallback `net_profit_owners / shares_outstanding` (EPS derived as net_profit_owners / shares (no reported EPS)); fallback `net_profit / shares_outstanding` (EPS derived as net_profit / shares (no reported EPS)) |
| `book_value_per_share` | per share | `total_equity / shares_outstanding` | Book value per share |
| `market_cap` | amount | `share_price * shares_outstanding` | Market capitalisation (also `mcap`, `marketcap`, `market_capitalisation`, `market_capitalization`) |
| `enterprise_value` | amount | `market_cap + net_debt + minority_interest + preferred_equity` | Enterprise value (market cap + net debt + minority interest + preferred equity) (also `ev`) - treated as 0 when not reported: `minority_interest`, `preferred_equity` |
| `pe` | times | `share_price / eps` | Price / earnings (also `p/e`, `pe_ratio`, `price_to_earnings`, `price_earnings`) - must be positive: `eps` |
| `pb` | times | `market_cap / total_equity` | Price / book (also `p/b`, `pb_ratio`, `price_to_book`, `price_book`) - must be positive: `total_equity` |
| `ev_ebitda` | times | `enterprise_value / ebitda` | EV / EBITDA (also `ev/ebitda`, `enterprise_value_to_ebitda`) - must be positive: `ebitda`, `bank.operating_profit`; fallback `market_cap / bank.operating_profit` (EBITDA proxied by bank pre-provision operating profit (PPOP); EV is not meaningful for a bank, so this is market cap / PPOP) |
| `ev_ebit` | times | `enterprise_value / ebit` | EV / EBIT - must be positive: `ebit` |
| `ev_sales` | times | `enterprise_value / top_line` | EV / sales - must be positive: `top_line` |
| `price_to_sales` | times | `market_cap / top_line` | Price / sales (also `p/s`, `ps`) - must be positive: `top_line` |
| `earnings_yield` | percent | `100 * eps / share_price` | Earnings yield |
| `dividend_yield` | percent | `100 * (abs(dividends) / shares_outstanding) / share_price` | Dividend yield (also `div_yield`) |
| `fcf_yield` | percent | `100 * free_cash_flow / market_cap` | Free cash flow yield - must be positive: `market_cap` |
| `roe` | percent | `100 * net_profit / total_equity` | Return on equity (period-end equity) (also `return_on_equity`, `roe_pct`) - must be positive: `total_equity` |
| `roa` | percent | `100 * net_profit / total_assets` | Return on assets (period-end assets) (also `return_on_assets`, `roa_pct`) |
| `roe_avg` | percent | `100 * net_profit / ((total_equity + prior(total_equity)) / 2)` | Return on average equity - must be positive: `total_equity`, `prior(total_equity)` |
| `roa_avg` | percent | `100 * net_profit / ((total_assets + prior(total_assets)) / 2)` | Return on average assets (the basis banking regulators use for banks) |
| `roce` | percent | `100 * ebit / (total_assets - current_liabilities)` | Return on capital employed (also `return_on_capital_employed`, `roce_pct`) |
| `roic` | percent | `100 * nopat / invested_capital` | Return on invested capital - must be positive: `invested_capital` |
| `ebitda_margin` | percent | `100 * ebitda / revenue` | EBITDA margin (also `ebitda_margin_pct`) |
| `ebit_margin` | percent | `100 * ebit / revenue` | EBIT margin (also `ebit_margin_pct`) |
| `net_profit_margin` | percent | `100 * net_profit / top_line` | Net profit margin (also `npm`, `net_margin`, `npm_pct`) |
| `pbt_margin` | percent | `100 * pbt / revenue` | Profit-before-tax margin |
| `effective_tax_rate` | percent | `100 * tax_expense / pbt` | Effective tax rate |
| `asset_turnover` | times | `top_line / total_assets` | Asset turnover |
| `equity_multiplier` | times | `total_assets / total_equity` | Equity multiplier - must be positive: `total_equity` |
| `incremental_net_margin` | percent | `100 * (net_profit - prior(net_profit)) / (top_line - prior(top_line))` | Change in net profit per unit of change in top line |
| `operating_leverage` | times | `(ebit - prior(ebit)) * prior(top_line) / (prior(ebit) * (top_line - prior(top_line)))` | Degree of operating leverage (% change in EBIT / % change in top line) - must be positive: `prior(ebit)` |
| `payout_ratio` | percent | `100 * abs(dividends) / net_profit` | Dividend payout ratio |
| `retention_ratio` | percent | `100 - payout_ratio` | Earnings retention ratio |
| `sustainable_growth` | percent | `roe * retention_ratio / 100` | Sustainable growth rate (ROE x retention) |
| `gross_margin` | percent | `100 * gross_profit / revenue` | Gross margin - fallback `100 * (revenue - cost_of_revenue) / revenue` (gross profit not reported; derived as revenue - cost_of_revenue); not computed for: bank, insurer |
| `quick_ratio` | times | `(current_assets - inventory) / current_liabilities` | Quick ratio ((current assets - inventory) / current liabilities) - not computed for: bank, insurer |
| `inventory_turnover` | times | `cost_of_revenue / inventory` | Inventory turnover - not computed for: bank, insurer |
| `receivables_turnover` | times | `revenue / trade_receivables` | Receivables turnover - not computed for: bank, insurer |
| `payables_turnover` | times | `cost_of_revenue / trade_payables` | Payables turnover - not computed for: bank, insurer |
| `dso` | days | `period_days * trade_receivables / revenue` | Days sales outstanding (also `days_sales_outstanding`) - not computed for: bank, insurer |
| `dio` | days | `period_days * inventory / cost_of_revenue` | Days inventory outstanding (also `days_inventory_outstanding`) - not computed for: bank, insurer |
| `dpo` | days | `period_days * trade_payables / cost_of_revenue` | Days payables outstanding (also `days_payables_outstanding`) - not computed for: bank, insurer |
| `cash_conversion_cycle` | days | `dso + dio - dpo` | Cash conversion cycle (DSO + DIO - DPO) (also `ccc`) |
| `current_ratio` | times | `current_assets / current_liabilities` | Current ratio - not computed for: bank, insurer |
| `cash_ratio` | times | `cash_and_equivalents / current_liabilities` | Cash ratio - not computed for: bank, insurer |
| `debt_to_equity` | times | `total_debt / total_equity` | Debt / equity (also `de`, `d/e`, `leverage`) - must be positive: `total_equity` |
| `debt_to_assets` | times | `total_debt / total_assets` | Debt / assets |
| `debt_to_capital` | times | `total_debt / (total_debt + total_equity)` | Debt / (debt + equity) - must be positive: `total_equity` |
| `net_debt_to_equity` | times | `net_debt / total_equity` | Net debt / equity - must be positive: `total_equity` |
| `net_debt_to_ebitda` | times | `net_debt / ebitda` | Net debt / EBITDA - must be positive: `ebitda` |
| `debt_to_ebitda` | times | `total_debt / ebitda` | Debt / EBITDA - must be positive: `ebitda` |
| `equity_to_assets` | percent | `100 * total_equity / total_assets` | Equity / assets |
| `equity_to_liabilities` | times | `total_equity / total_liabilities` | Equity / liabilities |
| `interest_coverage` | times | `ebit / finance_costs` | Interest coverage (EBIT / finance costs) (also `interest_coverage_ratio`) - not computed for: bank |
| `ocf_margin` | percent | `100 * operating_cash_flow / top_line` | Operating cash flow margin - not computed for: bank, insurer |
| `fcf_margin` | percent | `100 * free_cash_flow / top_line` | Free cash flow margin |
| `cash_conversion` | times | `operating_cash_flow / net_profit` | Operating cash flow / net profit - must be positive: `net_profit`; not computed for: bank, insurer |
| `capex_to_revenue` | percent | `100 * capex / top_line` | Capex / top line - not computed for: bank, insurer |
| `capex_to_depreciation` | times | `capex / depreciation` | Capex / depreciation - not computed for: bank, insurer |
| `cash_flow_to_debt` | times | `operating_cash_flow / total_debt` | Operating cash flow / debt |
| `revenue_ttm` | amount | `ttm(revenue)` | Revenue, trailing twelve months |
| `net_profit_ttm` | amount | `ttm(net_profit)` | Net profit, trailing twelve months |
| `ebit_ttm` | amount | `ttm(ebit)` | EBIT, trailing twelve months |
| `ebitda_ttm` | amount | `ttm(ebitda)` | EBITDA, trailing twelve months |
| `free_cash_flow_ttm` | amount | `ttm(free_cash_flow)` | Free cash flow, trailing twelve months |
| `eps_ttm` | per share | `ttm(eps)` | EPS, trailing twelve months (the sum of each period's EPS) |
| `roe_ttm` | percent | `100 * ttm(net_profit) / total_equity` | Return on equity on trailing-twelve-month profit - must be positive: `total_equity` |
| `roa_ttm` | percent | `100 * ttm(net_profit) / total_assets` | Return on assets on trailing-twelve-month profit |
| `roce_ttm` | percent | `100 * ttm(ebit) / (total_assets - current_liabilities)` | Return on capital employed on trailing-twelve-month EBIT |
| `net_profit_margin_ttm` | percent | `100 * ttm(net_profit) / ttm(top_line)` | Net profit margin, trailing twelve months |
| `ebitda_margin_ttm` | percent | `100 * ttm(ebitda) / ttm(revenue)` | EBITDA margin, trailing twelve months |
| `interest_coverage_ttm` | times | `ttm(ebit) / ttm(finance_costs)` | Interest coverage (EBIT / finance costs), trailing twelve months |
| `pe_ttm` | times | `share_price / eps_ttm` | Price / trailing-twelve-month earnings - must be positive: `eps_ttm` |
| `ev_ebitda_ttm` | times | `enterprise_value / ebitda_ttm` | EV / trailing-twelve-month EBITDA - must be positive: `ebitda_ttm` |
| `dividend_yield_ttm` | percent | `100 * abs(ttm(dividends)) / shares_outstanding / share_price` | Dividend yield on trailing-twelve-month dividends |
| `graham_number` | per share | `sqrt(22.5 * eps * book_value_per_share)` | Graham number (22.5 = 15 x 1.5, the classic P/E and P/B ceilings) - must be positive: `eps`, `book_value_per_share` |

| Name | Unit | Formula | Meaning |
|---|---|---|---|

## Indian forms (`india.*`, after `ind_as_xbrl.register()`)

### Ratios and derived quantities

| Name | Unit | Formula | Meaning |
